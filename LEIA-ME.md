# Estágio Fácil — telas para Behance

1. Suba **todos** os arquivos desta pasta num repositório do GitHub (mesma pasta, sem renomear).
2. Settings > Pages > Deploy from a branch > `main` / `(root)`.
3. Abra `https://SEU-USUARIO.github.io/SEU-REPO/index.html`.
4. Em cada tela, clique em **Copiar iframe** e cole no módulo **Embed** do Behance.

Parâmetros de URL: `?ui=0` esconde a barra de controle, `?modo=wireframe` abre em baixa fidelidade, `?vaga=job-2` (tela 2) escolhe a vaga.
Dentro do iframe o fluxo continua clicável (as telas navegam entre si).
